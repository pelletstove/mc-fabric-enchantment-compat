## Minecraft 26.2 port

Port to Minecraft 26.2 (Fabric, Java 25, Mojang mappings) on the `26.2` branch. Settings are read from `config/enchantmentcompat.json`; RoundaLib and Mod Menu are no longer needed. Covered by 7 GameTests.
